## 🌟 About Fit-Log

**Fit-Log** is a workout planning project built with **Next.js**. It helps users organize their exercise routine by creating and saving workout plans. It also displays the time needed for exercises in a plan, making it easier to understand and manage a workout session.

## ✨ Key Features

| Feature | Description |
| --- | --- |
| 📝 **Create Workout Plans** | Put together a workout plan that suits your routine. |
| 💾 **Save Your Plans** | Save a workout plan so you can keep it for later. |
| ⏱️ **Exercise Time** | See how much time each exercise takes according to the plan. |
| 🏋️ **Workout Organization** | Keep exercises organized as part of your planned workout. |

## ⚙️ Run Locally

Want to run Fit-Log on your computer? Follow these steps.

### ✅ Prerequisites

- [Node.js](https://nodejs.org/) installed on your computer
- npm (included with Node.js)

### 📥 Installation

**1. Clone the repository**

```bash
git clone https://github.com/mahadihasandevx/fit-log.git
```

**2. Move into the project folder**

```bash
cd fit-log
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the app**

Visit [http://localhost:3000](http://localhost:3000) in your browser.
